# Microfilter USA showcase

Public URL: https://ammteclab.com/microfilterusa/

Buildless HTML/CSS/JavaScript, deployed by the parent repository's GitHub Pages configuration. All site assets are relative so the folder can be moved to microfilterusa.com later. Change the absolute Open Graph image URL and FormSubmit `_next` destination when moving.

## Inquiry delivery

The form POSTs to FormSubmit for delivery to the owner's supplied Hotmail inbox. First use requires the recipient to click the activation email. Until activated, email delivery is not verified. FormSubmit provides an opaque recipient endpoint after confirmation; substitute it in the form action to remove the address from HTML source too. The address is not displayed on the page. Keep default reCAPTCHA enabled. No inquiry data is saved in GitHub or browser local storage. The visitor's email becomes the reply-to address. `thanks.html` confirms submission, not verified inbox delivery.

## Plumbing intake research — 17 November 2026

- Florida Residential Code 2023, Chapter 29, Tables P2906.4–5 lists water-service and interior-distribution materials separately: https://codes.iccsafe.org/content/FLRC2023P2/chapter-29-water-supply-and-distribution . PVC is a service-pipe option; this form does not recommend it for interior distribution. CPVC, PEX and copper are included in the code's distribution materials. Galvanized steel and polyethylene are included for existing-service identification. Polybutylene is an existing/older-material identification option, not a new-installation recommendation.
- The same code uses an 80 psi threshold for pressure regulation. Intake bands are measurement buckets, not claims about normal OUC pressure. No verified single Orlando residential pressure range was found. Sizes are nominal identification options (1/2 through 2 inches), not system-sizing recommendations.
- Charlotte Pipe's technical manual distinguishes pipe/fitting pressure ratings and temperature effects: https://global.charlottepipe.com/TECHNICAL/TECHNICAL%20AND%20INSTALLATION%20DATA/CHARLOTTE_PLASTICS_TECH_MANUAL.PDF . For example, listed Schedule 40 PVC pipe ratings at 73°F include 480 psi for 3/4 inch, 450 for 1 inch, 370 for 1-1/4 inch, 330 for 1-1/2 inch, and 280 for 2 inch. These are NOT home operating pressures or ratings for an installed filter assembly. The intake asks users to report only a visible marking, with “not sure” as default.
- Form integration: https://formsubmit.co/documentation . Native POST retains the provider's spam check. Owner activation and an end-to-end inbox receipt test are necessary before relying on production lead delivery.

Verify actual pipe, fittings, filter assembly ratings, water pressure and site conditions during assessment. This intake is not an installation design or code-compliance determination.
