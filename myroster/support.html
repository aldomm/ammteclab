Keep private information private.

Never send your password. Remove crew names, IDs and confidential information from screenshots unless strictly necessary and authorized.

Getting started

  1. Read the usage notices displayed on first launch.
  2. On the first-start page, enter your roster website address, authorized Crew ID and password. Existing users can update these in Settings. The airline code is optional for normal app use and required only for logbook exports.
  3. Choose the period and tap Sync. Authenticate using your device.
  4. Keep the app open while it retrieves and saves the requested months.
  5. Check the result against roster website. The status reports logout confirmation or local-only session cleanup.

Saved months and history

Use Saved Rosters to select months or open the saved current month and next month together. In the period selector, “Download past 12 months” requests the current month and previous eleven. Availability depends on roster website. Previously saved periods remain available offline until replaced or deleted.

Reading the matrix and details

Drag horizontally across dates. Rotate to landscape for more columns and less top UI; the visible day is preserved. Use two fingers to pinch and pan temporarily, then release to return to normal scale. Enable “Open roster at today” in Settings to start with today highlighted at the left edge. Tap a flight number for its card, swipe to another flight in the same duty, and tap an airport code for its reference card. The main information button opens period totals, statistics, expiries and other available period data.

Report-time reminders

In Flight Details, choose the report reminder link. Every sector uses the report time of its duty. Zero days means a time interval before report, in 15-minute steps. One or more days means a chosen local clock time on an earlier date. Add an optional title. Use the main bell to inspect or delete notifications, or add a rule for all report times. Allow notifications in iOS Settings; Focus, device settings and system limits can affect delivery. Review existing individual reminders if your roster changes.

Transfer saved rosters

Open Settings → Import / export roster backup. Save a backup to Files, then choose that file in the destination app and tap Import and merge. No roster sync is needed. Existing months remain, and a matching period keeps the more recently downloaded version. Backups contain personal roster and crew details; keep them private. Credentials, notifications and preferences must be set up separately.

Export to a logbook

In Settings → Export, enter your two-character airline code. Choose Export to CrewLounge PILOTLOG or Export to LogTen Pro, select dates, prepare the CSV and save it to Files. Your saved Crew ID is used for PIC/SIC matching.

Use the PILOTLOG Import Wizard for the PILOTLOG file. For LogTen on Mac, use File → Import from File → Flights. Both files use UTC, YYYY-MM-DD dates and HH:mm durations. Follow the in-app mapping instructions and review the import preview. For LogTen, disable automatic filling and recalculation that could replace the exported values; extra pilots may need custom crew fields.

Review the assumed actual-instrument time, alternating PM/PF assignments and landing counts against actual experience. Night is an estimate based on civil twilight; day is total minus night. Missing fields need attention and repeated imports can create duplicates. A roster export is not a verified logbook.

Try the demo

Open Settings → Open demo, including from Settings on the first-start page. The sample rosters and crew are fictional and do not require a roster website account. Demo data does not replace your saved personal rosters.

Connection problems

Check network access and your account in the official roster website system. If the app requests verification, use Connection, then Resume. If your password changed, save the new credentials in Settings. Do not repeatedly retry a rejected login. Include the displayed error when reporting a problem.

Weather and missing details

Weather refresh is separate from roster sync. PAX, gates, aircraft registration and crew detail availability depend on the source and when you last synced. No display guarantees that information is current or complete. Always consult approved operational sources.

Delete local data

Swipe to delete saved periods or remove all saved rosters in Settings. “Forget credentials and session” separately removes saved login credentials. Neither action changes your airline account.

Beta feedback

TestFlight builds may expire or contain defects. Use TestFlight feedback or email support. Include reproduction steps and the version/build shown in Settings. Never rely on this entertainment-only beta as an official record.
